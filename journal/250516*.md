# 2025-05-16 Log — General Affairs Request

## 📌 Context
Received a new request from the General Affairs department to track staff daily activities.  
Currently, the company manages this using Google Sheets, but the process is not efficient enough.  
The request is to move all activity tracking into a calendar-style view, similar to Google Calendar but simplified, focusing only on staff activity tracking.

## 👥 Stakeholders
- General Affairs department (requester)  
- End users: staff in the manufacturing company  
- Development team (Vietnam)  
- Translator and Japan-side support developers

## ⚠️ Challenge
- Existing Google Sheet tracking is cumbersome and lacks usability.  
- Need to design a new interface that balances simplicity with functionality.  
- Must ensure the calendar view is intuitive for non-technical staff.

## 🔧 How I Handled It
- Reviewed the current Google Sheet workflow to understand pain points.  
- Drafted an initial design concept for a simplified calendar view.  
- Compared features with Google Calendar to identify which elements to keep and which to simplify.  
- Outlined requirements for backend data handling to support daily activity entries.

## 🛠️ Environment
- Google Sheets (current system)  
- Proposed: Custom calendar interface (web-based)  
- Translation support for Japanese requirements

## 📊 Outcome
- Clear understanding of inefficiencies in the current system.  
- Initial plan drafted for a simplified calendar view tailored to staff activity tracking.  
- Alignment with General Affairs department on moving away from Google Sheets.

## 🎯 Lessons Learned
- Calendar-based visualization is more intuitive for daily activity tracking than spreadsheets.  
- Simplification is key: avoid overloading the interface with unnecessary features.  
- Direct engagement with end users ensures the design meets practical needs.

## 📌 Next Steps
- Validate the proposed calendar design with General Affairs.  
- Create a prototype for testing with staff.  
- Plan phased migration from Google Sheets to the new system.
