# 2025-04-24 Log — Timecard System Discussion

## 📌 Context
Discussion about the new timecard system with:  
- 2 Japanese sales staff  
- 1 translator  
- 2 Vietnamese developers  

Initial feedback focused on UI, but our strength is in logic. We noted that UI design support should come from a designer. The old Excel-based system was confusing and inefficient.

## ⚠️ Challenge
- Feedback was vague and general, making it hard to capture clear requirements.  
- Staff in General Affairs spend excessive time at the end of each month processing dispatcher data.  
- Needed to quantify the workload impact to understand the problem.  
- Sensitive data requires careful deployment planning.

## 🔧 How I Handled It
- Calculated workload: one staff member spent ~10 hours, and 4 staff together spent ~40 hours managing dispatchers.  
- Concluded that with the new system, staff time could be reduced to ~1 hour per person.  
- Clarified input/output requirements with translator.  
- Translator helped uncover deeper insights:  
  - Old system used VBA to track dispatchers.  
  - Staff responsible for maintaining it resigned, creating a gap.  
  - Users requested a new project to replace VBA tracking.  
  - Input data will come from another internal product already built to track dispatchers.  
  - This system will calculate staff salaries based on that input.  
- Asked about server deployment: users requested deployment on the same server as existing systems, but as a separate system due to privacy and sensitivity.  
- Users also requested master data for customers and customer holidays.  
- They prefer to input data themselves rather than rely on imports during the first relaunch.

## 📊 Outcome
- Quantified workload inefficiencies and demonstrated potential time savings.  
- Clarified input/output flows for the new system.  
- Identified deployment requirements for sensitive data.  
- Established clear master data needs.

## 🎯 Lessons Learned
- Always clarify **input and output** early in meetings.  
- Translators are essential for uncovering deeper insights.  
- Quantifying workload helps reveal the real impact.  
- Sensitive systems require careful deployment planning.

## 📌 Next Steps
- Recieved UI prompted from JP staff.  
- Integrate with existing internal product for dispatcher tracking.  
- Include master data for customers and holidays.  
- Deploy as a separate system on the same server for privacy.  
- Validate time savings with General Affairs staff.
