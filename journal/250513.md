# 2025-05-13 Log — Issue Tracking Setup

## 📌 Context
After 10 days of launch, issues were being tracked only via Zalo.  
This created difficulties for translators and developers to follow up effectively.

## 👥 Stakeholders
- Developers (Vietnam)  
- Translator (non-technical)  
- End users in Japan  

## ⚠️ Challenge
- Zalo-only tracking was fragmented and inefficient.  
- Difficult for translator and developers to maintain visibility on issues.

## 🔧 How I Handled It
- Created a new dedicated place for issue tracking.  
- Ensured both translator and developers could access and update progress.  
- Established clearer communication flow.

## 📊 Outcome
- Improved transparency and collaboration.  
- Reduced dependency on Zalo-only communication.  
- Issues now tracked in a centralized location.

## 🎯 Lessons Learned
- Proper issue tracking tools are essential for multi-team collaboration.  
- Centralized communication reduces misunderstandings and delays.

## 📌 Next Steps
- Continue monitoring issue tracking efficiency.  
- Adjust workflow based on feedback from translator and developers.
