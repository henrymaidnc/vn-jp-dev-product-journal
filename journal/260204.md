# 2026-02-04 Log

## 📌 Context
Setting up a staging server inside **WSL (Windows Subsystem for Linux) with Ubuntu 24.04** on Windows.  
This relates to the CI/CD pipeline and Docker environment configuration.

## 👥 Stakeholders
- Myself (developer/maintainer of the staging environment)  
- Project team relying on CI/CD builds and containerized services  

## ⚠️ Problem
- Could not pull Docker images inside WSL Ubuntu 24.04.  
- SSH connections conflicted with Docker setup.  
- Multiple Docker instances (Docker Desktop, Docker client inside WSL, and Docker server) caused confusion.  
- Logon session errors when run docker via SSH.  
- Docker Desktop showed Ubuntu 24.04 enabled in WSL integration settings, which was unexpected compared to other distros.  

## 🔧 How I Handled It
- Reviewed Docker Desktop vs Docker Engine setup.  
- Removed Docker Desktop to avoid conflicts.  
- Installed Docker client directly inside WSL Ubuntu VM.  
- Cleaned up duplicate Docker instances.  
- Investigated Docker Desktop’s WSL integration settings to understand why Ubuntu 24.04 appeared.  

## 🛠️ Environment
- Windows 11 host  
- WSL2 with Ubuntu 24.04  
- Docker Desktop (initially installed, later removed)  
- Docker Engine/CLI inside WSL Ubuntu  
- CI/CD pipeline tools  

## 🖼️ Supporting Images

## 📊 Outcome
- Docker client inside WSL Ubuntu now runs without conflict.  
- CI/CD pipeline can proceed with container builds.  
- SSH logon session errors reduced after removing duplicate Docker setups.  
- Clearer understanding of Docker Desktop’s WSL integration behavior.  

## 🎯 Lessons Learned
- Avoid mixing Docker Desktop with native Docker installation inside WSL — choose one approach.  
- Docker Desktop’s WSL integration explains why certain distros appear in settings.  
- Always verify which Docker daemon the client is connected to before troubleshooting.  

## 📌 Next Steps
- Continue monitoring CI/CD builds for stability.  
- Document Docker setup guidelines for the team to avoid similar conflicts.  
- Evaluate whether Docker Desktop is needed at all for future projects.
